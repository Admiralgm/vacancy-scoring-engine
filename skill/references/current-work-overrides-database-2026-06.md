# Current-Work Override Protocol

> **Discovered:** 2026-06-02, WTO Digital Learning Technology Specialist scoring
> **Pattern:** Initial score (58/100 — Stretch) was based on CV database alone, which showed no LMS admin experience. On learning User is actively doing Moodle + Canvas integration at Olivia Education, the score revised to 72/100 — a **14-point swing** changing the verdict from Stretch to Strong Fit.

## The Problem

The scoring engine's Parameter 7 (Competitive Realism) depends heavily on whether the candidate has done the core function before. When the CV database is the sole evidence source, there's a **staleness gap**: User updates his CV DB periodically, but 1-2 sentences of new bullets in a section 3.1 entry don't capture the full weight of current hands-on work.

## Protocol

### BEFORE scoring any role, check for current-work overlap:

1. **Read the active Olivia Education section (3.1)** — this is the only "Present" role. Its TAGS and bullet updates may have been added after the scoring engine's last calibration was written.

2. **Ask User directly: "Are you currently doing any work related to [core function of the role]?"** — A single yes/no from the user is worth more than any database search. This session proved that.

3. **If current work covers the core function**, apply this override to P1 and P7:
   - **P1 (Domain / Technical Fit)**: Score as if the CV had 2+ years of relevant experience in that domain. Current work IS experience — it doesn't need to be historical to count.
   - **P7 (Competitive Realism)**: This is the biggest swing. "Has never done X" becomes "Is actively doing X RIGHT NOW." Hiring panels value current demonstrated capability over historical experience. Raise P7 by 2-5 points depending on how directly the current work maps to the JD's primary function.

### Calibration anchor for this pattern

| Scenario | Original Score | Revised Score | Delta | Why |
|----------|---------------|---------------|-------|-----|
| WTO Digital Learning Tech Spec | 58 (Stretch) | 72 (Strong Fit) | +14 | Core function (LMS admin/integration) is current daily work, not historical gap |

### When NOT to apply this override

- Current work is tangential (e.g., doing connectivity strategy for a role requiring financial modelling)
- Current work is at a different grade/seniority level than the target role
- The user didn't confirm the nature of their current work — don't infer from vague role titles

## Integration with Batch Scoring

During batch scoring (70+ entries via AGENT), there's no user in the loop to ask. Use this heuristic:

- If the target role's core function includes **LMS administration, EdTech platform ops, digital learning technology, or Moodle/Canvas**, flag it for potential +10-14 P1+P7 uplift and add a note: "POTENTIAL CURRENT-WORK OVERRIDE — verify with Olivia Ed section 3.1 before finalising."
- If you cannot verify, score conservatively from the CV DB alone but flag it.
