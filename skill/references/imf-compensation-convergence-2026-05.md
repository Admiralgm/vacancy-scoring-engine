## ChatGPT Convergence Pattern — When It Drops to 3-5pt Inflation

In this session, ChatGPT's IMF score (76-82%) was only 3-5 points above mine (77%),
a dramatic improvement from the 15-20pt inflation of previous roles.

### Conditions when ChatGPT converges:
1. **Rare differentiator present** — Agentic AI is a genuinely rare capability that ChatGPT correctly identified as a differentiator
2. **Daily accountability matches thematic match** — the role's actual daily work (agentic AI architecture, MCP patterns, A2A) directly aligns with the candidate's production work — no need to bridge thematic → daily
3. **Hard filters all pass cleanly** — no language gaps, grade mismatches, or qualification disqualifiers to catch
4. **Grade level appropriate** — A11/A12 targets User's seniority well (not too junior like WTO Grade 7)

### Conditions when ChatGPT inflates 15-20pt (inverse of above):
1. **Thematic match strong but daily accountability weak** — e.g. "EdTech ✓" but daily work is Moodle admin ✗
2. **Hard filter (language, grade, education) present but treated as "soft gap"** — e.g. French "knowledge of the other" treated as desirable rather than screening filter
3. **Grade mismatch ignored** — role is too junior/too senior for 30-year profile
4. **Keyword trap not caught** — title promises tech domain but accountabilities are different

### Rule of thumb for adjusting external assessments:
- If role has ALL four convergence conditions: trust the external score within 5pt
- If ANY condition is violated: expect 15-20pt inflation — apply the full correction
